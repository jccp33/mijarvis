# MiJarvis: reglas de desarrollo

1. Cuando yo diga "Analiza el estado actual del proyecto" o algo similar se debe analizar a profundidad y detalle el repositorio actual y el repositorio remoto (en caso de que exista) con el fin de actualizar el contexto del chat o agente de IA.

2. Toda actualización o edición de archivos se debe hacer siguiendo la regla prioritaria "NO ROMPER LO QUE YA FUNCIONA", especialmente para archivos de código fuente y configuración del proyecto.
